# 函數畫布 SRS v7.5 實作與測試紀錄

交付日期：2026 年 10 月 19 日。需求依據為使用者提供的《數學函數視覺化互動網頁 SRS v7.5 整編版》文件版次 1.0，包含 90 條規範性需求、44 個驗收案例及 18 項待細化技術決策。

## 開啟與操作

下載 index.html 後直接用瀏覽器開啟，無須安裝或啟動伺服器。所有程式與樣式均在單檔內；沒有 CDN、外部字型、套件或網路請求。

1. 新增空白項目，輸入公式，或從「範例」「批次貼上」加入草稿。
2. 一般函數可寫 sin(x)、y=x²；隱函數可寫 x²+y²=25。參數式在同一欄分兩行輸入 x(t)=3*cos(t) 和 y(t)=2*sin(t)，可獨立設定 t 範圍。
3. 按「繪製全部函數」或 Ctrl／⌘+Enter 才提交；一般 Enter 保留換行用途。錯誤草稿不取代舊曲線，並顯示錯誤及「尚未更新」。
4. 可取消整批繪製。取消捨棄本批暫存結果，保留最後成功圖表、最新輸入及計算中已完成的改名／改色／排序／刪除操作。
5. 桌機可拖曳平移、滾輪縮放、懸停吸附；手機可單指平移、雙指縮放、輕觸吸附。精確取樣完成前暫停吸附。
6. 重新載入只恢復草稿、名稱、顏色、可見性、順序、參數範圍、視角與設定，不自動畫曲線；必須再次按「繪製」。

## 本次依全文修正的重點

首次開啟改為空清單與空圖；初始及重設視角的兩軸均至少涵蓋 −10 到 10。新增公式改為自動辨識，成組參數式使用同一個多行輸入區。補上上標、函數平方、指定底數 log、標準化重複檢查、批次部分成功、數學快捷工具、自訂名稱、全域線寬、舊公式收合檢視及整批進度／取消。

排序、排序復原及即時樣式更新直接重用既有曲線資料；不重新解析或取樣。圖例改放圖表下方，包含隱藏項目的名稱、顏色、可見性與局部計算狀態。手機輸入面板位於圖表上方。已移除固定 50 函數上限，改用動態取樣預算；依規格移除圖表及外部檔案匯入匯出入口。

整合測試涵蓋正常與錯誤輸入、部分成功、整批取消、數量百分比、排序與拖曳歷史、原生文字復原、隱藏驗證、重新顯示與局部取消、視角預覽、延遲結果競態、儲存降級、重載空圖、惡意輸入、超過 50 函數及手機手勢。競態分別控制舊視角、舊提交、隱藏、改名、改色、排序及刪除的完成順序，沒有僅以一般操作推論通過。

這些結果是**依下列實作預設值執行的測試證據**，不等同所有瀏覽器、正式效能、數值精度或特定無障礙合規等級已完成驗收。SRS 中尚未核定的參考裝置、量化效能／誤差門檻與平台矩陣，仍須由需求負責者確認。

## 技術細節採用的實作值

下表是本次實作決策紀錄，並非宣稱原文件已核定這些數字，也沒有修改需求基線或新增產品範圍。

| 技術項目 | 本次實作 |
| --- | --- |
| TD-01 優先序與數字 | ^ 右結合；負號低於 ^；乘、除及隱式乘法同優先序且左結合。支援十進位／科學記號及上標整數。−x^2=−(x^2)，2^3^2=512，sin²(x)=sin(x)^2。 |
| TD-02 白名單 | 僅 x、y、t 依類型使用；常數 pi／π、e、tau／τ；識別字不分大小寫。函數須括號；拒絕成員存取、賦值程式、字串及任意 JavaScript。實際數學函數清單見下方。 |
| TD-03 類型辨識 | 無等號為一般函數；y=E 或 E=y 且 E 不含 y/t 為一般函數；其他單一等式為隱函數。多個等號或不等式拒絕。 |
| TD-04 參數式 | x(t)=E、y(t)=E 任一行序；亦接受具 t 語意的 x=E、y=E。必須各有一個分量，可有常數分量。t 預設 0 到 2*pi，必須有限且下限小於上限；端點含取樣，範圍修改先為草稿。 |
| TD-05 重複比對 | 依 AST 固定結構比較，統一空白、上標、顯隱乘法及省略 y=，保留運算結構。比較既有提交與本次依序接受的草稿，排除同項目自身；批次亦比對現有有效草稿。參數式含數值 t 端點；一般函數不以 x 限域區分。隱函數不交換左右式，不作代數化簡。 |
| TD-06 手動範圍 | 可只指定一軸，保留該軸邊界並調整另一軸；指定兩軸則完整容納矩形，必要時擴展一軸。非預設視圖在容器變動時保持中心與單位比例；預設視圖則重新適配兩軸至少 ±10。 |
| TD-07 實數有效性 | 拒絕可由常數子樹、常數分母或固定對數底數證明無效的式子。局部 NaN 不使整條函數失效；有限視窗內沒有曲線只提示「目前沒有可見曲線」，不宣稱全域無解。隱藏項目也做解析與保守語意驗證，顯示時才完整取樣。 |
| TD-08 發布與版本 | 整批按下繪製時擷取候選草稿；暫存至批次完成後一次發布。錯誤項目沿用舊提交與幾何；取消不發布暫存。計算中較新草稿保留且標示尚未更新；名稱、顏色、順序、刪除使用即時狀態。視角變更取消進行中的提交並重取樣舊提交；每個重新顯示工作獨立取消。訊號、任務身分與視角版本皆在發布前檢查。 |
| TD-09 保存與進度 | 輸入變更後約 300 ms 保存；保存最新草稿與設定，不保存曲線、操作歷史或工作狀態。格式 v2，可轉換本工具先前 v1；損毀資料提示後開啟空白工作區。儲存失敗首次提示且不重複阻塞。進度分母為啟動時項目數，隱藏與錯誤驗證完成各算一項，可見有效項取樣後算一項；零項為 100%。 |
| TD-10 歷史與鍵盤 | 最多 100 步，另以約 32 MiB 幾何參照估算裁剪舊歷史。提交、增刪、排序、名稱編輯群組、樣式、設定與手勢入歷史；草稿逐字修改使用原生文字 Undo，並立即使應用程式 Redo 失效。排序及刪除復原直接重用編譯與曲線參照。 |
| TD-11 運算資源 | 使用主執行緒協作分批及原生 AbortController，取樣約每 8 ms 檢查讓出。解析器限制 4096 字元、1024 token／節點、64 層；產品一般公式／區間輸入 2048 字元。批次較長錯誤原文保留，超過 100 萬字元拒絕整批且保留輸入區內容。基準取樣預算流暢 65000、標準 145000、精細 260000 次，依裝置、可見項目數及模式動態縮放，設有每項資源上下界；沒有固定函數數量上限。正式回應延遲、記憶體及幀率門檻尚未核定。 |
| TD-12 取樣方法 | 一般函數與參數式使用中點誤差自適應細分及不連續斷線。隱函數由粗網格依穿越、中心符號與曲率局部細分，葉格以 Marching Squares 輪廓及殘差判斷排除極點假輪廓。視角操作中只轉換既有幾何，停止約 180 ms 後精確取樣；參數式取樣完整 t 區間，一般與隱函數使用可見範圍加小幅邊界。正式極小分支／誤差保證尚未核定。 |
| TD-13 吸附與格式 | 以螢幕距離、14 CSS px 半徑找最近可見線段；數值等距使用清單上層優先。固定位置的判斷為確定性順序。座標小數位依每單位像素比例調整，最多 10 位；大數值／超出適合小數顯示的值用科學記號，處理負零。顯示不代表解析精度。 |
| TD-14 安全範圍 | 中心絕對值 ≤10^12，比例 10^-6～10^8 CSS px／單位；另檢查中心量級與浮點解析度組合，避免約四分之一像素以上的表示誤差。越界保留舊視角並提示。 |
| TD-15 平台 | 本次驗證 Windows Edge 本機檔案與瀏覽器手機模擬；未聲稱其他平台已驗收。file URL 的 localStorage 權限依瀏覽器設定而異。 |
| TD-16 版面與操作 | 760 CSS px 以下採手機上下版面；輸入區上、圖表下，可收合輸入區。圖表 touch-action:none，輸入區內捲動，橫向短畫面允許頁面捲動。必要控制有文字／可存取名稱與焦點樣式；完整讀屏與實體螢幕鍵盤遮擋測試未完成。 |
| TD-17 視覺 | 六色色盤；預設全域線寬 2.4 px，可在 1～6 px 調整；預設跟隨系統，亦可手動淺／深色。網格、座標軸、刻度、吸附與十字游標預設開啟，彼此獨立。 |
| TD-18 批次與範例 | 保留原行文字，忽略空白行；連續相反 x/y 分量在任一行具有 t／(t) 語意時配對。無效配對保留供修正。名稱「函數 N」單調遞增且不重用，自訂重名允許，公式重複另行檢查。快捷工具插在游標處，函數樣板將游標置於括號內。範例為 y=x²、sin(x)、x²+y²=25、(x²+y²−1)^3−x²*y^3=0，另提供參數橢圓；全部只加入草稿。 |

支援的數學函數：sin、cos、tan、asin、acos、atan、sinh、cosh、tanh、asinh、acosh、atanh、sqrt、cbrt、abs、exp、expm1、floor、ceil、round、trunc、sign、arcsin、arccos、arctan、ln、log、log10、log2、atan2、pow、min、max、hypot、sec、csc、cot、sinc、factorial、fact。log 一參數為底數 10，兩參數可指定底數；ln 為自然對數；三角函數固定弧度。

## 未完成的正式驗收與數值限制

- 90 條規範性需求均已納入實作與對照，但尚未完成所有目標平台、參考裝置、正式誤差／效能門檻及讀屏條件的核定與驗收。下方測試通過只代表已記錄的情境與環境。

- 依 SRS 明確範圍，不提供不等式填色、角度制切換、完整代數等價、圖表／外部檔案匯入匯出、帳號、雲端、協作、符號推導、複數或 3D。
